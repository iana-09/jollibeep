# JolliBeep

JolliBeep is a PHP-based Jollibee ordering system built for a technical school project. Customers can browse menu items, choose a store, place orders, and manage their profiles. An admin page supports reviewing and managing orders.

## Built with

- PHP
- MySQL for local XAMPP setup, with optional Supabase PostgreSQL support
- HTML, CSS, and JavaScript

## Getting started

Run the project locally with XAMPP and configure its database connection in `db_connection.php`. For Supabase setup and migration, see [SUPABASE_MIGRATION.md](SUPABASE_MIGRATION.md).

Keep `supabase_config.php` and database exports private; they are excluded from Git.
